# Straylight-Project
### Overview
This project is designed to showcase real‑world database engineering concepts used in gaming and entertainment companies. This project models the backend data systems of a modern hero‑shooter RPG, supporting:

Team‑based and free‑for‑all match modes
Hero abilities, stats, and progression
Player accounts, profiles, settings, and currency
Weapons, items, inventory, crafting, and rarity systems
Combat logs, damage events, healing events, and status effects
Ranked ladders, leaderboards, and seasonal progression
Guilds, social systems, and world zones
Marketplace trading and price history
Logging, auditing, and monitoring tables for DBA operations


# Schema Design
The STRAYLIGHT schema contains 60 tables across 10 subsystems, all demonstrating:

Complex relational modeling
Nullable foreign keys for flexible game modes
Multi‑layered progression systems
High‑volume combat logging
Marketplace and economic modeling
Full audit and monitoring tables
